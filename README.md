# Movilidad-urbana-y-productividad-econ-mica
 Evalué cómo la movilidad urbana se relaciona con la productividad económica en las principales ciudades latinoamericanas. Para ello trabajé con datos reales de TomTom Traffic Index y OECD Cities,  limpié, combiné y analizé para identificar en qué ciudades conviene invertir en infraestructura de transporte.

## 🧠 Objetivo del análisis

- Identificar problemas de calidad de datos
- Construir un pipeline de limpieza reproducible
- Analizar segmentaciones, uniones entre datasets y análisis de relaciones entre variables
- Generar recomendaciones sobre las ciudades donde hay mayor oportunidad de mejora al incrementar inversión en infraestructura de transporte.

Se trabajó con los siguientes datasets: 
`tomtom_traffic.csv` → información de movilidad en principales ciudades de latinoamérica, incluyendo tiempo de tráfico y distancia del tráfico.
`oecd_city_economy.csv`→ información de tasas de contaminación ambiental, productividad y tasas de desempleo en las principales ciudades de latinoamérica.
