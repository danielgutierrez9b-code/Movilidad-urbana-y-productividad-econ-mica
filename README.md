# Movilidad-urbana-y-productividad-econ-mica
 Evalué cómo la movilidad urbana se relaciona con la productividad económica en las principales ciudades latinoamericanas. Para ello trabajé con datos reales de TomTom Traffic Index y OECD Cities,  limpié, combiné y analizé para identificar en qué ciudades conviene invertir en infraestructura de transporte.
